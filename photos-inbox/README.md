# پوشهٔ تحویل عکس — HELSA

عکس‌های تازه را **با نام SKU** اینجا بگذارید:

```
photos-inbox/HLA-0001.jpg
photos-inbox/HLA-0042.jpg
```

سپس:

```bash
python3 scripts/ingest-product-photos.py --dry-run   # بررسی، بدون نوشتن
python3 scripts/ingest-product-photos.py             # ساخت دارایی‌های نهایی
```

اسکریپت خودش قاب ۱:۱، تُن یکدست، و دو اندازهٔ WebP (۶۰۰ و ۱۲۰۰) می‌سازد و
گزارش می‌دهد کدام فایل نگاشت نشد یا خارج از سقف اصلاح بود.
